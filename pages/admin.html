How to publish changes

  1. Edit, add or remove entries below. A draft is kept in this browser automatically.
  2. Click Download timeline.json.
  3. Replace personal-site/data/timeline.json with the downloaded file.
  4. Redeploy the site. Comments and photos go live.

Uploaded photos are embedded into the JSON as compressed data URLs, so no separate image hosting is needed.
